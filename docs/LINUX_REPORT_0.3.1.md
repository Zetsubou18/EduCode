# Отчёт по обновлению EduCode 0.3.1 для Linux

Дата проверки: 24 октября 2026 года.

Система проверки: Ubuntu 24.04.1 LTS, x86_64, Wayland с XWayland.

## Что обновлено

- Перенесены общие исправления 0.3.1: единая версия приложения, очистка Python-консоли перед новым запуском, защита ввода `X`/`Ч` от ошибочных одиночных хоткеев, белый цвет обычных Python-переменных, обновление CodeLens после готовности Pyright и оптимизация Teacher Mode.
- Уменьшены нативные буферы консоли и терминала, исключены лишние полные обновления QML при каждом блоке вывода.
- Linux-сборщик Debian-пакета теперь получает версию из корневого `CMakeLists.txt`. Версия в интерфейсе, CLI и `.deb` больше не расходится.
- README обновлён для пакета `educode_0.3.1_amd64.deb`.

## Результаты проверки

- Release-сборка завершена успешно.
- `CoreTests`: пройден.
- `TeacherTests`: пройден.
- `EduCode --version`: `EduCode 0.3.1`.
- Linux desktop smoke: пройдены графический запуск, относительные и Unicode-пути, несколько файлов, Pyright, интерактивный Python, PTY с проектным `.venv`, локальный API, снимок окна и чистое завершение.
- Полный UI smoke: пройдены редактирование, подсветка переменных, CodeLens с настоящим числом ссылок, диагностика, консоль, терминал и всплывающие окна.
- Поток из 100 000 строк: нативный Python — 545 мс, отображение в IDE — 721 мс.
- Повторный запуск очищает консоль; старый вывод не остаётся.
- Тест интерфейса настроек и горячих клавиш: пройден.
- В проверенных журналах нет `Model not found`, переполнения очереди Teacher Mode, падения или фатальной ошибки.

## Состояние ноутбука

Активная команда `/usr/local/bin/EduCode` указывает на Release-сборку `/home/zetsubou/EduCode/out/build/linux-release/EduCode/EduCode`, поэтому установленный ярлык и команда уже запускают 0.3.1. Старая версия не была зарегистрирована в `dpkg`; создавать вторую конфликтующую установку в `/opt` не потребовалось.

Перед обновлением сохранена резервная копия исходников 0.3.0 на рабочем столе Ubuntu.
