# EduCode 0.3.1 — Windows и Linux

Небольшое исправляющее обновление с единым номером версии, надёжным перезапуском Python-консоли и меньшей нагрузкой при большом потоке вывода.

## Список изменений для пользователей

- Исправлено отображение версии: главная страница, раздел «О программе», команда `EduCode --version`, журнал и установщик теперь получают номер из одного источника.
- Python-консоль полностью очищается перед каждым новым запуском. Вывод и история предыдущей программы больше не накапливаются.
- Исправлена неработающая клавиша `X` (`Ч` в русской раскладке).
- Обычные переменные Python (например, `name = ...`) снова отображаются белым, а не цветом именованных аргументов.
- Исправлен ложный счётчик `0 ссылок` у классов и функций во время Teacher Mode и при медленном запуске Pyright.
- Teacher Mode больше не отключает учеников при накоплении кадров демонстрации на медленном соединении.
- Windows-установщик автоматически находит предыдущую установку и предлагает «Обновить» без ручного удаления старой версии.
- В Windows-установщик и его окно добавлена иконка EduCode.
- Настройки горячих клавиш больше не позволяют назначить одиночную печатную клавишу и тем самым заблокировать ввод текста.
- Старые ошибочные привязки одиночных клавиш автоматически удаляются при запуске.
- Уменьшены кратковременные зависания интерфейса при очень большом выводе Python-программы.
- Снижено постоянное потребление памяти буферами консоли и терминала.
- Имя Windows-установщика и версия в списке установленных программ синхронизированы с версией проекта.
